# Remove Unlinked Attributes

As a result of parsing, automated price list imports, or software failures, **Attributes** that are not linked to any product may accumulate in the database. These can be duplicates, attributes left behind after incorrect deletion, or ones reserved for future use.

Such attributes do not disrupt the store's operation on their own, but they can slightly slow down the search and complicate data management. If you want to get rid of attributes not linked to products, this tool will help you make a decision and perform the cleanup.

To use the tool, you must apply a filter. Select **Groups** by checking the corresponding box in the tree. You can select all groups at once by checking the uppermost box.

:::warning  
Deletion is irreversible. Before using the tool, make sure that the unlinked attributes will not be needed in the future, for example, as a reserve.  
:::
