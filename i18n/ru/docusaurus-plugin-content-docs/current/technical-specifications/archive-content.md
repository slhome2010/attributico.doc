# Структура архива

```bash

Attributico_v3.5.0/
    │── PHP7.2-7.4/
    │     └── attributico.3.x.ocmod.zip
    │             └── upload/
    │                   ├── admin/
    │                   │    ├── controller/
    │                   │    ├── language/
    │                   │    ├── model/
    │                   │    └── view/
    │                   └── system/
    │                         └── library/
    │                               └── attributico/
    │                                     ├── attributico.php
    │                                     ├── interlink.php
    │                                     └── ...
    │
    │
    ├── News3.5.0/
    └── README.md

```

## Назначение папок и файлов

- `upload/` папки с файлами собственно модуля для OpenCart версии 3.х;
- `attributico.3.x.ocmod.zip` установочный архив для магазинов версии 3.x;
- `News/` папки с описанием изменений, исправлений и вспомогательными материалами;
- `README.md` краткая инструкция по установке и работе модуля;

## Различие версий

Приведенная структура архива соответствует версии модуля \> 3.5.0. Название папки `PHP7.2-7.4/` соответствует версии PHP. Разница в ioncube-кодировке некоторых файлов модуля для разных версий PHP. Внутри этих папок находится `attributico.3.x.ocmod.zip` - установочный архив для магазинов OpenCart версии 3.x.
