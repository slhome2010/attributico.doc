# Удаление

## Шаг 1: Деактивация модуля

В административной панели:

- Перейдите в *Расширения ⇒ Модули*;
- Напротив модуля "Attribut&co" нажмите "Деактивировать".

## Шаг 2: Удаление модификаторов

- Для OpenCart 3.x: удалите файлы `attribut&co.3.x.ocmod.xml` (если копировали в `/system`).
  Либо удалите модификаторы в *Расширения ⇒ Модификаторы*.

## Шаг 3: Удаление файлов модуля

- Перейдите в *Расширения ⇒ Установка расширений*;
- Удалите все записи `attributico3.x.ocmod.zip` в истории установок.

:::danger
Никогда не делайте этого при совместном использовании **Attribut&co** и **Attribut&pro**
:::

## База данных

При установке модуля создаются дополнительные [таблицы](technical-specifications/database.md).

:::tip
При удалении модуля таблицы и поля в БД **не удаляются**. Если необходимо, удалите их вручную через PhpMyAdmin.
:::
