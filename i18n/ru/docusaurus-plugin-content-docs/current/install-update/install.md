# Установка

## Шаг 1: Скачивание файлов

Скачайте установочные файлы модуля с доступного вам ресурса. В результате у вас должны быть zip архив:

```bash
Attributico_v3.5.0.zip
```

Структура архива описана в [этой](/technical-specifications/archive-content.md) статье.

## Шаг 2: Распаковка и загрузка файлов

Распакуйте архив. Откройте папку, соответствующую [вашей версии PHP](/technical-specifications/compatibility.md).

В административной панели:

- Перейдите в _Расширения ⇒ Установка расширений_;
- Загрузите файл `attributico.3.x.ocmod.zip` для магазинов третьей версии (3.x) из этой папки.

## Шаг 3: Активация модуля

В административной панели:

- Перейдите в _Расширения ⇒ Модули_;
- Найдите модуль "Attribut&co";
- Активируйте модуль.

## Шаг 4: Настройка прав пользователей

Права пользователей устанавливаются автоматически при активации модуля, но если это не удалось по какой либо причине, сделайте это самостоятельно.

В административной панели:

- Перейдите в _Система ⇒ Пользователи ⇒ Группы пользователей_;
- Установите разрешения на просмотр и редактирование для:
  - `extension/module/attributico`;

## Шаг 5: Проверка регистрации событий

В административной панели:

- Перезагрузите страницу.

После выполнения всех шагов в меню _Каталог ⇒ Атрибуты_ появится пункт _Attribut&co_.

:::warning
**Очистите кэш магазина и браузера.**
Специфика очистки кэша для OpenCart 3.x описана [здесь](https://shopiweb.ru/opencart-3/kesh-opencart-3-ochistka-kesha/).
:::

Если пункт _Attribut&co_ не появился, перейдите в _Расширения ⇒ События_ и проверьте, что все события зарегистрированы.
Если событий не зарегистрировано, перейдите в _Расширения ⇒ Модули_ и деактивируйте и снова активируйте модуль "Attribut&co".
