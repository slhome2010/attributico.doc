# Новое в этой версии

1. Самое важное - изменение структуры файлов и папок модуля. Теперь модуль можно устанавливать через установщик OpenCart и нет необходимости использовать FTP для перезаписи файлов на сервере.

2. Уменьшения кода модификаторов в пользу событий. Преимущества:

- Уменьшение количества конфликтов;
- Возможность перехода на OpenCart 4 в будущем.
