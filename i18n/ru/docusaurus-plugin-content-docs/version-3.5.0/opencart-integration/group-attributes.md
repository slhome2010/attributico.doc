# Атрибуты группы

Существует возможность добавить все **Атрибуты группы**, выбранной из списка, непосредственно в форме товара.

Из выпадающего списка можно выбрать **Группу**, **Атрибуты** которой вы хотите добавить в товар.

Групп может быть много, поэтому работает автодополнение — поиск и фильтрация в списке по мере ввода символов названия группы.

| ![Выбор группы](/img/tutorial/v350/group_autocomplete.png) |
| :--------------------------------------------------------: |
|              _Выбор группы с автодополнением_              |

После выбора группы, все **Атрибуты** этой группы добавляются в форму товара.
