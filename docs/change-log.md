# What's New in This Version

1. Complete removal of OCMOD. Now everything operates via event registration. How to update: [documentation](/install-update/update.md).
2. Improved the 'Merge duplicates' tool algorithm. It works faster and more efficiently. Added logging.
3. Improved the algorithm of all module functions for the product form.
4. Synchronized library classes for compatibility with Attribut&pro and new OpenCart versions.
